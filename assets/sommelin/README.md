# Sommelin Character Assets

正式なソムリン君キャラクター素材。

## Files

- `sommelin-logo.png`: アプリアイコン、アバター、チャット導線用の正式ロゴ
- `sommelin-expression-sheet.png`: 8種類の全身ポーズを収録した表情シート

## Expression Order

上から順に以下の状態として使用する。

1. スワリング
2. グラスを見る
3. 香りを確認する
4. 感動・マリアージュ
5. 感動して涙する
6. 通常案内
7. ボトル紹介
8. おすすめ紹介

小さい表示ではロゴを使用し、会話画面や体験演出では全身ポーズを使用する。
